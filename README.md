## What I Learned

While building TinyTask, I practiced some basic front-end development concepts:

- **HTML:** I used elements such as headings, text inputs, lists, and containers to structure the page and create the to-do list layout.
- **CSS:** I learned how to style the page with colors, spacing, rounded corners, shadows, fonts, flexbox alignment, and pseudo-elements. I also used CSS classes to change the appearance of completed tasks.
- **JavaScript:** I used `querySelector` to access elements, event listeners to respond to keyboard and mouse actions, and DOM methods to create, add, update, and remove to-do items.
- **Putting it together:** I connected the HTML, CSS, and JavaScript so users can press Enter to add a task, click a task to mark it complete, and remove it with the delete button.
